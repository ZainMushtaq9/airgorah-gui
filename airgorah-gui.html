Live Only — Data Save Nahi Hota

Ye page data store / save nahi karta — koi database, koi file, koi browser storage nahi. Scan, clients, handshakes aur tumhara add kiya hua target sirf is khuli hui tab mein live nazar aate hain. Refresh, tab band, ya page dobara kholna = sab clear aur scan naye siray se shuru. Export / download ka button bhi is liye hata diya hai.

Sach ye hai: browser asal WiFi hardware ko access nahi kar sakta, is liye yahan ka live feed simulated demo data hai jo har 2 second update hota hai — asal live scan ke liye neeche wali cheezein chahiye hongi.

➕ Koi Network / Target Add Karna Ho To

  1. Neeche ➕ Add Target button dabao — form khul jayega.
  2. SSID likho — tumhare WiFi ka naam, jaisa phone mein nazar aata hai.
  3. BSSID likho — router ka MAC address, format AA:BB:CC:DD:EE:FF. Ye router ke peechay sticker par ya router settings 192.168.1.1 mein milta hai.
  4. Channel, Band (2.4 / 5 GHz) aur Security (WPA2 / WPA3) chuno. Apna password test karna ho to woh bhi optional field mein likh sakte ho — woh bhi save nahi hota.
  5. ✓ Target Add Karo dabao — network foran live list mein aa kar select ho jayega. Galat add ho jaye to bas page refresh kar do, clear ho jayega.

Asal (real) live scan ke liye ye add karna hoga: Linux PC, monitor-mode wala WiFi adapter, aur usi PC par chalta hua asal Airgorah — browser wali ye page akele asal WiFi scan nahi kar sakti. Sirf apna network add karo.

➕ Manual Target Add Karo — Sirf Live Session Ke Liye

Apna WiFi yahan likh kar target banao — SSID aur BSSID likho, channel aur security chuno. Add hote hi ye scan list mein aa jayega aur khud select ho jayega, phir us par Capture / Dictionary Test chala sakte ho. Ye target save nahi hota — page refresh ya band karte hi ye bhi clear ho jayega. Sirf apna network add karo. BSSID router ke peechay sticker par ya router settings (192.168.1.1) mein milta hai.

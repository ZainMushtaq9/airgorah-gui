1 Target Ka Address Likho

BSSID router ke peechay lage sticker par likha hota hai, ya router settings 192.168.1.1 → Wireless mein milta hai. Format aisa hota hai: AA:BB:CC:DD:EE:FF. Sirf apna WiFi daalna hai.

Sach baat, saaf likhi hai: browser asal WiFi hardware ko access nahi kar sakta, is liye yahan output demo (simulated) hai — lekin run bilkul asal Airgorah jaisi hai: wohi 10 commands, usi order mein, wohi output. Asal live run ke liye yehi address Linux PC par asal Airgorah + monitor-mode adapter ke saath chalega. Yahan kuch save nahi hota — refresh karte hi sab clear.
